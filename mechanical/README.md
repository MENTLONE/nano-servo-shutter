# Original shutter mechanism files

The original Servo-Shutter STL archive is maintained by the upstream creator. Download it from the original repository:

- [Servo shutter STLs.zip](https://github.com/hackaninstant/Servo-Shutter/blob/main/Servo%20shutter%20STLs.zip)
- [Original Servo-Shutter project](https://github.com/hackaninstant/Servo-Shutter)
- [Thingiverse model](https://www.thingiverse.com/thing:6033871)

Extract the archive into this `mechanical/` directory. The archive is intentionally not mirrored in this repository at present, so the upstream creator retains the canonical copy and attribution stays clear.

Check the upstream repository and Thingiverse page for the applicable license/terms before redistributing the STL files. The software license in this repository does not automatically change the license terms of third-party mechanical files.
