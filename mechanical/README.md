# Mechanical files — Thingiverse 6033871

This folder documents the mechanical shutter model supplied for this project.

## Original model and attribution

**Servo operated leaf shutter** by **jamesskelton** on Thingiverse:

- Thingiverse: https://www.thingiverse.com/thing:6033871
- The supplied archive's own README identifies this as a remix of an earlier servo-operated leaf shutter. It describes thicker actuating portions on the shutter leaves, a top cover, an adjusted 9 g servo support height, and a mount for a 360 mm LOMO process lens.
- The archive's included `LICENSE.txt` states: "Creative Commons - Attribution". The archive does not specify a license version, so retain that notice and consult the Thingiverse page for the exact current license terms before redistributing.

**Electronics/software reference:** https://github.com/hackaninstant/Servo-Shutter

The Thingiverse mechanical model author (jamesskelton) and the Arduino/software repository author (hackaninstant) are distinct credits; this project acknowledges both.

## Assembly note from the source README

The source instructions say to trim a standard servo horn down to its hub, glue the hub into the gear, and fasten the gear to the servo after installing the servo in the shutter body. Verify fit, clearances, servo direction, and leaf motion on the bench before powering or using a laser.
